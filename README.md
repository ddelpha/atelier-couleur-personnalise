# Atelier Couleur — Personalised one-page site (€199)

Fictional French house painter, evolving the €149 mini demo at https://ddelpha.github.io/atelier-couleur-mini/.

Same cream, charcoal, terracotta and sand identity. Added detailed services, an about section, four-image inspiration gallery, work process and five native expandable FAQs. Compare links connect the two independent package examples; prices are package prices, not upgrade fees. All contact details are illustrative and inactive. Real TEI links lead to the website provider.

Static HTML/CSS. No build, JavaScript, external fonts, trackers or forms. Search indexing disabled. Preview: `python3 -m http.server 8767`.
